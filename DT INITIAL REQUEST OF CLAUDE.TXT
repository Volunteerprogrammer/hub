Changes to the site.

We need a new variable in the HUB status data: "Event". This is a multivalue variable containing a boolean value for each of the emergencies that might trigger the opening of the HUB: BUSHFIRE, STORM, HEATWAVE. In most situations only one will be true at any time, but it's possible for e.g. BUSHFIRE and HEATWAVE to both be true.

We need these options to be managed in the Admin popup.

The status of the HUB (OPEN or CLOSED) and, if the HUB is OPEN, the value of Event will now determine several aspects of the site, as follows:
	
	Status=CLOSED

The focus changes to the display of key information with maximum clarity and a minimum of distracting elements. 
		
		In this mode, the "Where is it?" page becomes site's the landing page and the menu text should become caps. In that page, the #div.callout.callout-amber is hidden. 		The status-banner element should display the nature of the emergency, as specified in the Event variable.
